# Ноутбуки

| Файл | Задача |
| --- | --- |
| [cv_flowers.ipynb](cv_flowers.ipynb) | Классификация цветов, MobileNetV2 |
| [cv_detection.ipynb](cv_detection.ipynb) | Детекция животных, YOLOv8n |
| [detect_goods.ipynb](detect_goods.ipynb) | Классификация овощей, CNN на Keras |
| [object_detection.ipynb](object_detection.ipynb) | Детекция номеров, котов и часов, Haar Cascade |

Рабочая директория Jupyter — эта папка. Рядом должны лежать `flower_photos/`, `model/` и `test_images/` (см. README в каждой из них). Для `object_detection.ipynb` в этой же папке лежат Haar-каскады и тестовые JPEG. Animals-10, Vegetable Image Dataset и `yolov8n.pt` подтягиваются при выполнении соответствующих ноутбуков.
